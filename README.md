# Data Cleaning & Regex Utility

A lightweight, mobile-friendly Python utility designed to clean messy text data, remove noise, and handle standard text preprocessing tasks using Regular Expressions (Regex).

## Features
- Removes URLs, special characters, and digits efficiently.
- Normalizes whitespaces and converts text to lowercase.
- Perfect preprocessing script (`text_cleaner.py`) for data preparation workflows.

## Tech Stack
- Python
- Regular Expressions (Regex)
